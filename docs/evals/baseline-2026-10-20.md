# Baseline report, 2026-10-20 (Task 15)

Docs ref: `stable`, 229 pieces, 31 pages. Dev set: 24 questions (`evals/data/dev.jsonl`): 15 answerable, 9 not answerable from the docs. Embeddings: `bge-base-en-v1.5`. Answers: the user chain (Cloudflare `gemma-4-26b-a4b-it`, thinking off; no fallback was needed). Grading is by code only (page and heading match, citation checks). **No judge has read any answer text**, so "answered" means "answered with a valid citation", not "answered correctly".

**Noise warning.** 15 answerable questions means one question moves a rate by 6.7 points. A 12/15 versus 14/15 gap is two questions. Read every number below as a direction, not a result.

Meaning led, but with this few questions I cannot say it beats hybrid. In the earlier spike (S6, 13 questions) hybrid won. The two disagree, and neither has enough data to settle it.

Total for both runs: 614.6 neurons, `stopped_early: False`. Hybrid's extra refusals (r-001, r-010) follow directly from its retrieval misses.

**Known failures**
- r-007 (colour a cell when its value equals a word, on every sheet) is refused in both modes although `colors:9` is ranked first. Replayed once: the model replied "couldn't find this". That page documents `color-cell` for the current sheet, so the refusal may be fair (the question asks for every sheet). Needs a human read; the gold label may be too optimistic.
- r-001, r-010: retrieval misses (above).
- All 5 real "docs gap" questions (g-001 to g-005) and all 4 invented or off-topic ones were refused. This is the reassuring result, but the g-questions were labelled "gap" by a keyword check of the docs, so a good answer there would have meant a label error.

## 3. Paste-all (whole docs in one prompt, one model, 5 questions)

| Question | Result | Neurons | Seconds |
|---|---|---|---|
| r-002 | answered | 351.6 | 7.9 |
| r-008 | answered | 344.1 | 5.0 |
| d-003 | answered | 345.6 | 6.3 |
| g-002 | refused (correct) | 343.4 | 4.8 |
| t-002 (prompt injection) | refused (correct) | 343.3 | 4.3 |

About 345 neurons per question (estimate was 320): **27 times** the cost of a retrieval answer, 5 to 8 seconds. In the 3 answered cases the model cited a relevant piece, though r-002 also cites an unrelated piece alongside the right one. Correctness has not been judged. With 5 questions this says nothing about quality, only about cost. Paste-all at 345 neurons would allow about 29 questions per day on the free tier, against about 770 for retrieval answers.

## Addendum: dev set revised (28 questions), retrieval re-run, 2026-10-20

Changes after cold review #2 and the owner review step (the sections above stay as first run):
- **r-004:** now also accepts the `save-restore` page (`also_gold_pages`), because meaning search found a page that does answer it.
- **r-007:** reworded from "on every sheet" to "on the sheet I am looking at". The docs only describe `color-cell` for the current sheet, so the first wording asked for more than they say. **This was changed after seeing the result**, so r-007 is no longer comparable with the first run.
- **Added k-001 to k-004:** four key/symbol questions (`&`, `!`, `^`, `*`), written from the docs' own key tables. The reviewer pointed out that the first set had none, so it never tested what hybrid search is for. I chose keys that have a clear defining entry, so this favours keyword-style search; read it as "does hybrid keep that strength", not as proof it is best.

Retrieval only (no answers re-run, so no new neuron spend), `docs/evals/retrieval-2026-10-20b.json`:

| Mode | All 19 answerable | The 4 key questions | Misses |
|---|---|---|---|
| keyword | 15/19 | 4/4 | r-001, r-004, r-007, r-010 |
| meaning | 16/19 | 1/4 | k-001, k-003, k-004 |
| hybrid | **17/19** | 4/4 | r-001, r-010 |

Reading: meaning search cannot find a key by its symbol, keyword search cannot bridge vocabulary ("lookup table" is not "join"), and hybrid covers both on this set. That supports keeping hybrid as the default. It is still 19 questions, so a gap of one or two questions is inside the noise. The first run's "meaning 14/15 vs hybrid 12/15" is explained by the set having no key questions, not by meaning being better.
