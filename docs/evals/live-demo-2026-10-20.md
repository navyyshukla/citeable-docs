## First AI judge run (Gemini `gemini-3.5-flash-lite`, public dev questions only): UNCALIBRATED
- Run 1: 11 of 16 "grounded", 1 call failed (HTTP 503, transient). Cause found: the judge saw only the cited pieces,
  renumbered from 1, while the answers cite the original excerpt numbers. A judge-input bug, not wrong answers.
  Fixed (judge now shows every excerpt in the order the answerer saw them), commit "judge shows every excerpt...".
- Run 2 after the fix: 17 of 17 grounded, 17 of 17 correct, 0 errors.
- Verified: the Gemini request shape (`x-goog-api-key` header, `systemInstruction`, `generationConfig`) works.
- Caveat: "17 of 17 correct" proves nothing until the owner hand-grades about 25 answers and `judge-agreement` is run;
  a judge that never says "wrong" would look the same. Lesson: a judge needs its input checked by reading the
  prompt it received, not only by testing the code.
