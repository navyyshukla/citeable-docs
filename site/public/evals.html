r-002 How can I search and replace text inside every cell of one column? (answerable; answered; hand-graded: correct; AI judge (rough filter, misses docs errors and unhelpful answers): correct)

To replace text in the selected rows of your current column, use the `g*` command followed by the *regex* (the pattern you are looking for) and the *subst* (the text you want to replace it with) [3]. If you want to transform the text in-place instead of creating a new column, you can use the `g*` variant of the `*` command [1]. To do this for all rows in a column, first move your cursor to that column, press `gs` to select all rows, and then press `g*` [1].

Sources: Columns, Editing Contents

r-003 I have an int column with empty-looking null values. How do I select all the rows where it is null? (answerable; answered; hand-graded: correct; AI judge (rough filter, misses docs errors and unhelpful answers): correct)

You can select all rows where the current column is null using one of these methods: - Move to an empty or `None` cell in the column and press `,` to select all empty and `None` cells [1]. - Move to a `None` cell and type `z,` to select all rows that contain `None` in that column [1]. - Move to an empty cell and type `z.` to select all rows that have an empty cell in that column [1]. - Open a **DescribeSheet** for the current sheet with `Shift+I`, move to the **nulls** column, move to the row referencing your column of interest, and type `zs` to select all null rows for that column [1]. - Use `z|` followed by a Python expression; for non-numerical columns, typing `z| not ColumnName` will select all empty and `None` cells [1]. For numerical columns, this will also select cells with `0` [1].

d-004 How do I rename a column? (answerable; answered; hand-graded: correct; AI judge (rough filter, misses docs errors and unhelpful answers): correct)

You can rename a column using several methods: The preferred method is to use the `^` command to edit the name of the current column [5]. You can also rename a column using the **Columns sheet**: 1. Press `Shift+C` to open the **Columns sheet** [1]. 2. In the **name** column, move the cursor to the row for your source sheet [1]. 3. Type `e`, input the new name, and press `Enter` [1]. 4. Press `q` to return to your source sheet [1]. Other specific renaming commands include: * `z^`: Sets the name of the current column to the contents of the current cell [5]. * `gz^`: Sets the name of the current column to the combined contents of the current column for selected rows [5]. * `g^`: Sets the names of all unnamed visible columns to the contents of the selected rows or the current row [5].

d-005 I recorded my steps earlier. How do I run them again on a different file? (answerable; answered; hand-graded: correct; AI judge (rough filter, misses docs errors and unhelpful answers): correct)

To reuse your recorded steps (the cmdlog) on a different input file, you must first make the cmdlog filename-independent [1]. 1. Save your cmdlog by pressing `Shift+D` to open the cmdlog and `Ctrl+S` to save [2]. 2. Edit the `.vdj` file to perform these two actions: * **Remove** the `open-file` line (the line containing `"longname": "open-file"`) [2]. * **Erase all `"sheet"` values** (for example, using `gs gzd`). Leaving a sheet name blank tells VisiData to "use the current sheet," allowing commands to operate on whatever is at the top of the stack [2]. 3. Replay the steps on your new file by running the following command: `vd -b -p cmdlog.vdj newfile.csv -o output.tsv` In this command, the new file is passed as a positional argument, `-p` replays the cmdlog against it, `-b` enables batch (non-interactive) mode, and `-o` writes the result [2]. Note that blank sheet names only work for linear workflows where you do not switch between sheets [2]. If your analysis involves switching sheets or joining them, you must either keep the sheet names or use stack-relative commands like `Ctrl+^` (`jump-prev`) or `gCtrl+^` (`jump-first`) to navigate [2].

Sources: Save and Restore, Save and Restore
