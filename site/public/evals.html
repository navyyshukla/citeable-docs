r-002 How can I search and replace text inside every cell of one column? (answerable; answered; hand-graded: correct; AI judge (rough filter, misses docs errors and unhelpful answers): correct)

To replace text in the selected rows of your current column, follow these steps (the Columns > How to substitute text in a column): 1. Select the rows you wish to transform by pressing `gs` to select all rows. 2. Press `g*` to replace matching *regex* (a pattern) in the current column for the selected rows with *subst* (the replacement text) [1, 3]. 3. Type the text you want to find in the search field. 4. Press `Tab` to move to the replace field, type your replacement text, and press `Enter` [1]. If you want to perform the transformation in-place instead of creating a new column, use the `g*` variant [1].

Sources: Columns, Editing Contents

r-003 I have an int column with empty-looking null values. How do I select all the rows where it is null? (answerable; answered; hand-graded: correct; AI judge (rough filter, misses docs errors and unhelpful answers): correct)

You can select all rows where the current column is null using these methods: - Move to an empty or `None` cell in the column and press `,` to select all empty and `None` cells in that column [1]. - Move to a `None` cell and press `z,` to select all rows containing `None` in that column [1]. - Move to an empty cell and press `z.` to select all rows that have an empty cell in that column [1]. - Open a **DescribeSheet** for the current sheet by pressing `Shift+I`, move to the **nulls** column, move to the row referencing your column of interest, and press `zs` to select all null rows for that column [1]. - Use `z|` followed by `not ColumnName` to select all empty and `None` cells for non-numerical columns (for numerical columns, this will also select cells with `0`) [1].

r-007 How do I colour a cell green whenever its value equals a certain word, on the sheet I am looking at? (answerable; answered; hand-graded: correct; AI judge (rough filter, misses docs errors and unhelpful answers): correct)

To color a cell green whenever its value equals a certain word, you can use the `color-cell` command to attach a CellColorizer to your current sheet [1]. After you run `color-cell`, a form will appear where you must enter two things [1]: 1. The Python expression in the `expr:` field (for example, `column_name == 'your_word'`) [1]. 2. The color in the `color:` field, such as `green` [1]. If the expression you provide is truthy (evaluates to true), the cell will be painted that color [1]. Note that if you encounter errors where cells are not coloring as expected, it may be because the column type is incorrect; you can set the column type using `#` for integers or `%` for floats [2].

d-004 How do I rename a column? (answerable; answered; hand-graded: correct; AI judge (rough filter, misses docs errors and unhelpful answers): correct)

To rename a column, you can use one of the following methods: **Using the Columns sheet** 1. Press `Shift+C` to open the **Columns sheet** [1]. 2. Within the **name** column, move the cursor to the row which represents the source sheet [1]. 3. Type `e`, input the new name, and press `Enter` [1]. 4. Press `q` to return to the source sheet [1]. **Using the `^` command** The `^` command edits the name of the **current** column and is often the preferred method [5]. **Other methods** * `z^` sets the name of the **current** column to the contents of the **current** cell [5]. * `gz^` sets the name of the **current** column to the combined contents of the **current** column for **selected** rows [5]. * `g^` sets the names of **all unnamed visible** columns to the contents of the **selected** rows or the **current** row [5].

d-005 I recorded my steps earlier. How do I run them again on a different file? (answerable; answered; hand-graded: correct; AI judge (rough filter, misses docs errors and unhelpful answers): correct)

To replay your recorded steps (the cmdlog) on a different file, you must first make the cmdlog filename-independent [1]. 1. Save your cmdlog by pressing `Shift+D` to open the cmdlog and `Ctrl+S` to save [2]. 2. Edit the `.vdj` file to make the following changes [2]: * **Remove** the line that contains `"longname": "open-file"`. * **Erase all `"sheet"` values** (you can do this with `gs gzd`) so that sheet names are blank; a blank sheet name tells VisiData to use the current sheet [2]. 3. Run the following command to replay the cmdlog against your new file [2]: `vd -b -p cmdlog.vdj newfile.csv -o output.tsv` In this command, `-p` replays the cmdlog, `-b` enables batch (non-interactive) mode, and `-o` writes the result [2]. Note that using blank sheet names only works for linear workflows where you do not switch between sheets [2].
